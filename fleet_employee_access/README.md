# Manuale rapido per l'utente finale: come registrare una nuova auto

## Prima di iniziare

L'amministratore deve:
- darti un permesso sul **Parco veicoli** (*Impostazioni › Utenti*): **Utente Base: solo i propri veicoli**, **Manager: gestisce tutti i veicoli** oppure **Amministratore**;
- collegare il tuo utente alla tua scheda dipendente. Senza questo collegamento l'Utente Base non vede nessuna auto.

## Registrare un'auto

1. Apri l'app **Parco veicoli** › **Le mie auto** (il Manager vede tutte le auto anche da **Parco veicoli › Parco veicoli**).
2. Clicca su **Nuovo**.
3. Compila:
   - **Modello** (obbligatorio): es. *Fiat/Panda*. La marca si ricava dal modello.
   - **Targa**: es. GA123BB.
   - **Dipendente**: per l'Utente Base è già il proprio nome. Il Manager sceglie il dipendente o lo lascia vuoto.
   - **Colori** (scheda **Modello**): uno o più, es. Bianco e Nero.
4. Clicca su **Salva**.

Se il modello non c'è, il Manager scrive il nome nel campo **Modello** e sceglie **Crea e modifica...**, poi sceglie o crea la marca. L'Utente Base deve chiederlo al Manager.

## Chi può fare cosa

| | Utente Base | Manager | Amministratore |
|---|---|---|---|
| Vedere e modificare | Solo le proprie auto | Tutte | Tutte |
| Registrare | Solo per sé | Per chiunque | Per chiunque |
| Assegnare a un altro dipendente | No | Sì | Sì |
| Cancellare | No | Sì | Sì |
| Creare marche, modelli e colori | No | Sì | Sì, anche da *Configurazione* |

## Messaggi frequenti

- **«Solo un Manager o un Amministratore del parco veicoli può assegnare un veicolo a un altro dipendente.»** Clicca su **Abbandona** e chiedi al Manager.
- **Non vedo nessuna auto.** Il tuo utente non è collegato a un dipendente, oppure non hai auto assegnate.
