# Manuale rapido per l'utente finale: come registrare una nuova auto

## Prima di iniziare

L'amministratore deve:
- darti il permesso **Parco Auto (autonomo)**, come **Utente Base** o **Manager** (*Impostazioni › Utenti*);
- collegare il tuo utente alla tua scheda dipendente. Senza questo collegamento non vedi nessuna auto.

## Registrare un'auto

1. Apri l'app **Parco Auto** › **Le mie auto** (il Manager può usare anche **Tutte le auto**).
2. Clicca su **Nuovo**.
3. Compila:
   - **Targa** (obbligatoria): es. GA123BB. Spazi e minuscole vengono corretti da soli.
   - **Marca** e **Modello** (obbligatori): scegli dall'elenco. Il modello mostra solo quelli della marca scelta.
   - **Colori**: uno o più, es. Bianco e Nero.
   - **Dipendente**: per l'Utente Base è già il proprio nome. Il Manager sceglie il dipendente o lo lascia vuoto.
   - Facoltativi: **Anno di immatricolazione** e **Note interne**.
4. Clicca su **Salva**.

Se una marca, un modello o un colore non c'è, il Manager può crearlo direttamente dal campo (**Crea e modifica...**) o da **Configurazione**. L'Utente Base deve chiederlo al Manager.

Un'auto che non si usa più va archiviata (**Azioni › Archivia**), non cancellata.

## Chi può fare cosa

| | Utente Base | Manager |
|---|---|---|
| Vedere e modificare | Solo le proprie auto | Tutte |
| Registrare | Solo per sé | Per chiunque |
| Assegnare a un altro dipendente | No | Sì |
| Cancellare | No | Sì |
| Creare marche, modelli e colori | No | Sì |

## Messaggi frequenti

- **«Esiste già un'auto con questa targa.»** La targa è già registrata: cercala nell'elenco.
- **«Solo un Manager del parco auto può assegnare un'auto a un altro dipendente.»** Clicca su **Abbandona** e chiedi al Manager.
- **Non vedo nessuna auto.** Il tuo utente non è collegato a un dipendente, oppure non hai auto assegnate.
